# IRONCORE Strength Gym

Clean, responsive single-page gym website.

## Folder structure

- `index.html` — semantic page structure and content
- `css/styles.css` — base styles and a separated UI/UX polish section
- `js/app.js` — page data, animations, carousels, counters, forms, and accessibility behavior

Open `index.html` directly or serve this folder with any static web server.
